## 中文说明

本目录归档需求评审纪要、上线验收检查表与版本迭代复盘总结。

- **文件命名规范**：遵循日期前缀 `YYYY-MM-DD-<主题>`。
- **发布归档纪律**：正式发布（Released）状态必须在此归档真实的线上验证记录或验收签署。

<a name="english"></a>
## English Overview

This directory archives requirement review minutes, production acceptance checklists, and version retrospective summaries.

- **File Naming Convention**: Prefix with date `YYYY-MM-DD-<topic>`.
- **Release Verification Gate**: Marking requirements as Released strictly requires archiving verifiable live production evidence or formal sign-off records here.
