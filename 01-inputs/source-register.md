## 登记规则 (中文)
- 原始材料不静默改写。
- 同一材料出现新版本时新增记录，保留旧版本。
- 正式需求必须引用来源 ID。

## Registration Rules (English)
- Raw materials must never be silently rewritten.
- When new versions of a source arrive, add a new row and preserve previous entries.
- Formal requirements must explicitly cite their source ID (`SRC-XXXX`).
