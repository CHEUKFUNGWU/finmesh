<a name="中文"></a>
## 中文说明

本目录维护版本发布计划、范围承诺（Scope）与里程碑。

- **子目录命名约定**：`v<主版本>.<次版本>`（如 `v0.1`）。
- **范围承诺文件**：每个版本目录下维护独立的 `scope.md` 作为开发排期与验收的唯一法定边界。

---

<a name="english"></a>
## English Overview

This directory maintains release rollout plans, scope commitments, and development milestones.

- **Subdirectory Naming**: `v<major>.<minor>` (e.g., `v0.1`).
- **Scope Commitment Files**: Each version subdirectory maintains an independent `scope.md` acting as the authoritative boundary for development scheduling and release acceptance.
